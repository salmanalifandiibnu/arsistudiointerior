# Arsi Studio Interior — Official Landing Page

Website resmi studio spesialis *Design & Build Custom Interior* berbasis di Arcamanik, Kota Bandung, Jawa Barat. Dibangun dengan fokus pada kecepatan, kejujuran material arsitektur, dan konversi calon klien langsung ke WhatsApp.

## 📐 Fitur Utama

- **Sinematik Scrollytelling Hero (300 Frame):** Visualisasi transisi denah arsitektur 2D menuju ruang hunian jadi dengan akselerasi kanvas HTML5.
- **Interactive Before/After Slider:** Perbandingan transformasi lapangan mentah dinding semen menjadi dapur modern presisi milimeter.
- **Arsip Portofolio Fotorealistik (26 Proyek):** Bento grid responsif dengan sheet spesifikasi teknis modal (Body Scroll Lock, Keyboard Accessibility, Deep WhatsApp Lead Attribution).
- **Edukasi Kejujuran Material:** Bedah spesimen inti (Plywood Meranti 18mm, Blockboard Kayu Solid, PVC Board kedap air) dan mitra resmi hardware (TACO, AICA, CARTA, HÄFELE, HUBEN).
- **Pelacakan UTM & Debounced Anti-Double Fire:** Pelacakan sumber kampanye iklan dan atribusi otomatis pada pesan WhatsApp.
- **Standar Tipografi Arsitektur (Bahnschrift DIN):** Kombinasi font Bahnschrift, Plus Jakarta Sans, dan JetBrains Mono.

## 🛠️ Tech Stack

- **Framework:** React 19 + TypeScript
- **Bundler:** Vite 6
- **Styling:** Tailwind CSS 3
- **Icons:** Lucide React
- **Deployment:** Netlify

## 🚀 Panduan Menjalankan Lokal

```bash
# 1. Install dependencies
npm install

# 2. Jalankan server pengembangan
npm run dev

# 3. Build untuk produksi
npm run build

# 4. Pratinjau hasil build
npm run preview
```
